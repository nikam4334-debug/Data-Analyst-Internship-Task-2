# Superstore Sales Analysis – Data Analyst Internship Task 2

## Project Overview

This project focuses on Data Visualization and Storytelling using the Superstore sales dataset.

The objective is to analyze sales performance, identify business trends, visualize important metrics, and generate actionable business insights.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Dataset Overview

The dataset contains 9,994 records and 9 columns.

Key fields include:
- Order Date
- Region
- State
- Category
- Sub-Category
- Segment
- Sales
- Profit
- Quantity

## Project Workflow

1. Dataset loading and exploration
2. Data cleaning and preparation
3. Exploratory data analysis
4. Data visualization
5. Sales dashboard creation
6. Business insights and storytelling
7. Business recommendations

## Key Business Insights

- Highest revenue-generating region: West
- Highest revenue-generating category: Technology
- Most profitable subcategory: Copiers
- Lowest-profit subcategory: Tables
- Leading customer segment: Consumer
- Best sales month: November 2017
- Lowest sales month: February 2014
- Overall profit margin: 12.47%

## Business Recommendations

- Study successful sales strategies in the West region.
- Evaluate opportunities in Technology products.
- Review pricing and costs associated with Tables.
- Strengthen Consumer customer retention.
- Plan inventory around high-sales periods.

## Project Deliverables

- Python analysis notebook
- Original dataset
- Sales dashboard image
- PDF analysis report
- Business insights report

## Conclusion

This project demonstrates how Python-based data analysis and visualization can help businesses understand sales performance, profitability, customer segments, and regional trends.
